# 背上的山河
壮族背带文化数字叙事展。React + TypeScript + Vite，GSAP / ScrollTrigger、SVG、Canvas，无后端。

当前版本已恢复为纯2D五幕叙事展览，取消3D入口及自动跳转。旧的 `?mode=3d&zone=4` 地址同样展示2D首页。原3D源码与上传素材保留供归档参考，不进入网页运行包，历史3D测试不纳入当前测试集。下文3D相关内容为历史记录。

构建输出可离线打开的 `dist/exhibition-preview.html`。五幕叙事、图片观察、纹样问答、故事浏览、祝福卡1200×1600 PNG导出继续可用。

## 本地运行
需要 Node.js 20.19+ 或 22.12+（本环境验证 Node 24）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
```

```sh
npm run build
npm run preview
```

五幕包含序章分镜、背带热点和生活场景、纹样观察问答、故事卷轴与文献阅读、1200×1600 PNG祝福卡。可键盘操作，支持小屏与减少动态效果设置，音频默认不启用。

## 内容管理
`src/data/` 的 exhibits、patterns、stories、sources JSON 管理展品、纹样、叙事和出处。`verified` 表示内容核验状态；`publishable` 控制故事是否可进入正式叙事。未核实展品只能以清晰标注的图像观察资料展示。艺术化改编必须明确类型，不能冒充史实。`npm run check:content` 在构建时自动执行。

素材来自用户提供的两份 Word 文档。当前已完成交互作品，尚未完成原始图版、文献及授权核验，不能宣称完成正式竞赛资料审查。详见 SOURCE_AUDIT.md。不得将文中的侗、苗、水等民族资料无差别归为壮族。

## 验证

```sh
CHROMIUM_PATH=/usr/bin/chromium npx playwright test
```

浏览器测试默认使用环境已有的 `/usr/bin/chromium`；其他机器通过 `CHROMIUM_PATH` 指向已安装的 Chromium。

## 第一人称3D展厅
- 支持 WebGL2 时，顶部显示“进入3D沉浸式展厅”。2D组件仍保留，返回时恢复滚动位置与已输入的祝福。
- 桌面：点击“开始WASD漫游”锁定鼠标，WASD/方向键行走，鼠标环视，E查看当前展区；Esc或“解锁鼠标”暂停。镜头固定1.6米，无跳跃，走廊墙体保留碰撞半径。
- 手机/触摸设备：不连接行走控制，仅使用五个点位按钮；点位见 `src/data/gallery-points.json`。尊重减少动态效果设置。
- 点击画框、展签或“查看本区展品”打开 Html 资料弹窗。纹样区复用现有JSON完成观察问答；尾厅直接复用2D祝福卡组件和1200×1600 PNG导出。
- 浏览器不支持WebGL2时不显示入口；运行中上下文丢失自动回到2D。锁定鼠标受浏览器/iframe权限限制时仍可点位参观。

### SVG浮雕素材（当前缺失）
程序只引用 `public/assets/textures/wenyang1-1.svg`、`wenyang2-1.svg`、`wenyang3-1.svg`。当前仓库没有这三个文件；未生成任何替代素材。缺失画框和资源清单会明确提示，原有图像和问答仍可使用。将有授权的SVG放到相应位置后刷新或重建即可加载。

SVGLoader忽略白色背景，使用其他填充/描边作为几何数据，统一金色金属材质，3.5厘米厚，最大边1.45米；每个SVG合并成一个Mesh，无倒角，超过复杂度预算则提示精简。测试中的简单SVG是内存里的几何算法输入，不是发布素材。

### 性能策略
3D代码延迟到进入模式后加载；低多边形箱体构成走廊，两个无阴影射灯，不使用光追、后处理或粒子；DPR桌面上限1.5、手机1；静止时按需渲染，退出时释放场景和监听。浏览器自动化使用软件WebGL验证功能，未宣称实测某款核显的帧率。

## 尾厅文创岛台
尾厅替换为中央独立岛台，3.2×3米，四周可通行。哑光柜体、透明玻璃、金色包边与灯带均由基础几何体构成；四盏无阴影射灯在尾厅照亮展柜，环境高光使用32像素立方贴图一次生成，无外部HDR、模型或光追。玻璃不拦截展品点击，关闭昂贵的实时透射与持续环境捕捉。

`src/data/wenchuang.json` 管理id、name、source、description、image，另含简易陈列类型model与verified。选中文创可查看居中大图、来源与说明，切换九类文创；图录内可进入原数字祝福卡编辑器。Esc、遮罩和关闭按钮退出预览；图录与编辑切换保留当前祝福内容。

柜台碰撞与跳转绕行共用 `islandLayout.ts` 的尺寸，人物不会穿过柜体；尾厅点位调整为正面偏右，视高仍为1.6米。2D页面保持原样。

### 实际图片仍待接入
本次检查当前工作区及origin/main时，没有用户所述patterns素材目录或文创图片。现在已建立 `public/assets/patterns/README.md` 列出期望文件名；界面明确提示缺图，不以其他藏品代替。JSON中的名称及说明依据用户本次提供的文创参考图整理，出处及授权仍标记待核。将真实文件同步到该目录并修改image字段后重新构建即可。不得将测试用的纹理响应当成真实产品图。

### 更新：使用一张文创合照
文创已改为共用 `patterns/wenchuang-board.webp`，在 `wenchuang.json` 为每件设置crop归一化矩形。无需九张独立图片。尾厅与预览弹窗均有“导入这张文创合照”入口，选择完整4:3 PNG/JPG/WebP即可从原像素自动裁切九类文创。浏览器本地处理，不上传、不生成新图案；切换2D再回3D仍保留当前会话的图片。正式部署将合照保存为上述WebP路径；独立HTML也会内嵌该图。聊天内嵌图没有自动挂载到当前文件系统，实际原图仍需导入或以文件附件提供。

## 独立展柜与鼠标控制更新
尾厅现为4.2×2.35米的封闭亚克力展柜：黑色哑光底柜、浅灰台板、细金框与底部灯带；背景暗红，顶部暖金线光及柜内暖红灯带。中后部拱形网格架并排挂两件娃娃，上下花形吊饰与红流苏；左侧包、杯，右侧方形抱枕与手机壳，前排横放伞、眼罩与多枚贴饰。位置和拾取体见islandLayout.ts的PRODUCT_LAYOUT。未导入图片时显示明确标注的当代几何造型示意，非传统纹样或实物精确复原；原图纹理仍通过既有合照导入获取。

鼠标现在无需锁定即可操作：尾厅左键拖拽环绕，其他区域拖拽原地环视；滚轮调整FOV（28—85°），拖拽不误触详情。点击开始WASD后进入第一人称，支持锁定鼠标；锁定受限时仍启用WASD＋拖拽。Esc停止。移动端保持点位参观。展品有独立拾取盒、悬停金色高亮；亚克力罩不参与鼠标拾取，实体柜台仍有漫游碰撞。

初始展柜相机为正面俯视，2.95米高，以完整展示柜体；第一人称漫游仍固定1.6米高。可打开 `/?mode=3d&zone=4` 直达尾厅。构建另输出“背上的山河-3D展柜预览.html”，支持WebGL时直接进入该展柜；不生成ZIP。
